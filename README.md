# kenar narayaka — personal site

Static personal website. Hosted via GitHub Pages.

## Files
- `index.html` — home
- `about.html` — about
- `blog.html` — blog (coming soon)
- `style.css` — styles (dark/light theme)
- `script.js` — theme toggle + ASCII fractal renderers (Mandelbrot, Julia set, L-system tree)
- `logo.jpeg` — profile image

## Deploy to GitHub Pages
1. Create a new repo named `yourusername.github.io` (or any repo name for a project site)
2. Push all files to the `main` branch
3. Go to repo Settings → Pages → Source: `main` / `/(root)`
4. Site will be live at `https://yourusername.github.io`

## Customise
- Replace placeholder `[...]` text in `about.html`
- Update GitHub/LinkedIn URLs in all three HTML files (search `kenarnarayaka`)
- Update email in `index.html`
